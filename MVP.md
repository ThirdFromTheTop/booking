1. Регистрация нового клиента: Отправка данных на POST /api/auth/register, хэширование пароля и запись в таблицу users.
2. Аутентификация и вход: Проверка пароля на POST /api/auth/login` и выдача криптографического JWT-токена.
3. Защищенный гостевой режим: Автоматическая блокировка форм бронирования и админки для неавторизованных гостей.
4. Поиск доступных отелей: Загрузка и рендеринг объектов с itemType: HOTEL через открытый эндпоинт GET /api/items.
5. Поиск доступных авиабилетов: Загрузка и рендеринг объектов с itemType: FLIGHT из базы данных PostgreSQL.
6. Просмотр карточки инвентаря: Динамический вывод названия, типа, цены (pricePerUnit) и остатка мест (availableInventory) на UI.
7. Выбор параметров заказа: Интерактивный выбор ID объекта инвентаря и ввод количества мест на фронтенде.
8. Резервирование ресурса: Создание записи в таблице bookings со статусом PENDING через POST /api/bookings/create.
9. Защищенное извлечение личности: Автоматическое и доверенное получение userId на бэкенде из расшифрованного JWT-токена.
10. Автоматический расчет стоимости: Математическое перемножение цены на количество мест, выполняемое доменной моделью Booking.java.
11. Контроль овербукинга: Мгновенная отмена транзакции на слое домена, если запрашиваемое количество мест превышает остаток в БД.
12. Автоматическое списание мест: Вычитание забронированных мест из availableInventory и сохранение обновленного инвентаря в БД.
13. Просмотр личных записей: Получение клиентом истории только своих бронирований через защищенный эндпоинт GET /api/bookings/my.
14. Отмена бронирования клиентом: Полное удаление транзакции заказа из базы данных через эндпоинт DELETE /api/bookings/{id}.
15. Автоматический возврат мест: Программное прибавление отмененных мест обратно к инвентарю объекта в PostgreSQL.
16. Авторизация Администратора: Ограничение доступа к панели управления — интерфейс админа открывается строго для роли ROLE_ADMIN.
17. Добавление объекта админом (Create): Программное создание и запись нового отеля/рейса в базу через POST /api/items.
18. Изменение параметров объекта (Update): Инфраструктурное обновление цен или остатков мест админом через PUT /api/items/{id}.
19. Удаление объекта админом (Delete): Полное и безвозвратное стирание отеля или рейса из СУБД через DELETE /api/items/{id}.
20. Безопасный выход (Logout): Очистка хранилища localStorage.clear() в браузере, уничтожающая сессию и токен.
